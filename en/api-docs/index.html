WARDEN/API & DEVELOPERS

API & DEVELOPERS

Integrations with clear boundaries.

Public API v1 is part of the architecture. Business endpoints, API key issuance and the sandbox are not available yet.

01

Available technical endpoint

GET /api/v1/health checks only the web process response. It does not confirm database, Redis, email or business-feature availability. It returns status, service and version.

02

What is planned

User and guarantor checks, Telegram/Discord ID checks, scopes, limits, usage analytics and signed webhooks with replay protection.

03

API privacy

Public responses will not expose original evidence, internal notes or protected information. Third-party integrations require Owner approval.

GET /api/v1/health
{
  "status": "ok",
  "service": "warden-web",
  "version": "0.1.0"
}
